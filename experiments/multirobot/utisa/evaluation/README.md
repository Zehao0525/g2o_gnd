# evaluators/utisa

Offline tools for UTIAS MR.CLAM (UTISA) datasets and C++ result trees.

```bash
python experiments/multirobot/utisa/evaluation/plot_trajectory_comparison.py
python experiments/multirobot/utisa/evaluation/compare_batch_ape.py
python experiments/multirobot/utisa/evaluation/plot_single_robot_observations.py
python experiments/multirobot/utisa/evaluation/plot_unit_experiment.py
python experiments/multirobot/utisa/evaluation/visualize_dataset.py
python experiments/multirobot/utisa/evaluation/generate_mrclam_gt_dataset.py --help
```

Shared helpers: `common.py` (`evaluators.utisa.common`).
